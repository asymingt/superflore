# Superflore Bazel Generator
This generator creates `MODULE.bazel` files for ROS packages, allowing them to be managed as Bazel modules.

## Usage

You can run the generator using the `superflore-gen-bazel` command (if installed via setup.py) or directly via python module.

```bash
# Generate for a specific distro (e.g. jazzy, kilted, rolling)
superflore-gen-bazel --ros-distro kilted --dry-run --output-repository-path /path/to/overlay
```

## Generated Output

The generator produces a directory structure compatible with a Bazel registry or an overlay repository:
```
ros-<distro>/
  <package_name>/
    MODULE.bazel
```

## Features

- Generates `MODULE.bazel` with `bazel_dep` declarations.
- Maps `build`, `run`, and `test` dependencies to Bazel dependencies.
- Handles version resolution from the ROS distro.
- Supports generating for specific packages via `--only`.

## Notes

- External dependencies (non-ROS system keys) do not currently map directly to `bazel_dep` unless they are also treated as modules.
- The `BUILD.bazel` file is NOT generated by this tool (it is assumed to be provided by another mechanism).
